# Convenciones del proyecto

## Estilo de escritura

- **Prohibido usar em dashes (—)** en cualquier parte del proyecto: copy de la web, UI,
  comentarios, código, mensajes de commit y documentación.
- En su lugar usar puntuación normal según el contexto: coma, dos puntos (`:`),
  paréntesis, guion simple (`-`) o middot (`·`).
- Tampoco usar en dashes (–); aplicar el mismo criterio.

## Visibilidad del repositorio

- **Este repo debe quedarse PÚBLICO.** La web (yaltoque.com) se sirve con GitHub
  Pages y en el plan gratuito Pages solo funciona con repos públicos: si se
  vuelve privado, la página se cae. Es solo la landing estática, sin secretos.
- Los repos de código sí son privados: finance-app y finance-tracker
  (la conexión de Railway con finance-tracker es por GitHub App y no depende
  de la visibilidad).
